A deliberate hybrid

Rust controls.
Node executes.

Native coordination where determinism and bounded concurrency matter. Real JavaScript semantics where ecosystem compatibility matters. That split now has receipts: 3.95× faster discovery, but 2.83× slower when 48 files each pay for a fresh worker.
