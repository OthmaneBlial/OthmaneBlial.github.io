# Roadmap

## Foundation — available now

- deterministic simulator with 24 scenes;
- Halo, globe, constellation, ambient and forensic Canvas modes;
- recording, replay, scrubbing, seeds and speed control;
- nine themes, reduced motion, high contrast and keyboard controls;
- local WebSocket/SQLite server and responsive phone controller;
- Linux OS-metadata Rust provider;
- Docker, Raspberry Pi appliance assets, CI and privacy contract gates.

## Capture depth

- local MaxMind ASN/country database adapter;
- hardened opt-in PCAP header provider;
- macOS Network Extension and Windows ETW research;
- router adapters with explicit per-model capability documents;
- device alias persistence and discovery confidence.

## Spatial light

- WebGL 3D globe after a measured Canvas comparison;
- projector calibration and ceiling projection geometry;
- network storms and time-lapse history;
- optional locally generated ambient soundscape and spatial audio;
- AR companion exploration.

## Ecosystem

- signed, local-only provider packages;
- versioned recording import/export;
- reproducible demo capture tooling;
- multilingual control surface.

Every roadmap feature remains subordinate to the no-content privacy contract and local-first operation.
