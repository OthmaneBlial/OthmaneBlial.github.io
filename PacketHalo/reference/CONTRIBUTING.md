# Contributing to PacketHalo

PacketHalo values beauty, privacy, honesty, and maintainability in that order only when they do not conflict—privacy is always a release blocker.

1. Install Node 22+, pnpm 10, and stable Rust.
2. Run `pnpm install` and `pnpm dev`.
3. Keep the simulator path permission-free and immediately impressive.
4. Run `pnpm verify` before opening a pull request.

New flow fields require a privacy review in both TypeScript and Rust contracts. New classifiers must expose a confidence score and use uncertain language below the service-confidence threshold. Renderer work must be tested with reduced motion, keyboard navigation, 1080p, and a narrow phone viewport.

Small modules and explanatory names are preferred. Comments should explain a non-obvious constraint, not restate code.
