01

First light

Quick start

PacketHalo launches with a deterministic synthetic scene. You do not need an account, token, packet-capture permission or external service.

RuntimeNode.js 22.5+22.23.2 pinned
Packagespnpm 10.15+Lockfile included
OptionalRust 1.95Linux agent only
Terminal 
git clone https://github.com/OthmaneBlial/PacketHalo.git
cd PacketHalo
pnpm install
pnpm dev

Open http://127.0.0.1:5173. The phone controller is on 5174, and server health is available at 8787/health. Movie Night starts automatically.

Port already occupied?Set PACKETHALO_WEB_PORT, PACKETHALO_CONTROL_PORT and PACKETHALO_PORT before starting.
02

Observe and shape

Controls

The primary journey stays inside one instrument: choose a scene, move through visual grammars, pause the field, then record or focus when something matters.

SpacePause or resume observation
MMove to the next visual mode
CHide or reveal instruments
FEnter or leave fullscreen

Five visual grammars

Halo is the default sculpture. Globe foregrounds geography. Constellation clusters services. Ambient removes most interface text. Forensic adds ports, ASNs, protocols and confidence without becoming a table-first dashboard.

Record and replay

Recordings contain only validated FlowEvent values and are capped at 10,000 events. Browser imports are capped at 10 MB. Pause, scrub, jump to the next event, replay at several speeds, or export the JSON recording locally.

04

Non-negotiable

Privacy contract

PacketHalo observes relationships, not conversations.

May be processed

  • Endpoints and ports
  • Transport and inferred protocol
  • Byte or packet counts when available
  • Process name when the OS exposes it
  • Country, ASN and organization
  • Timestamp, source and confidence

Never inspected or stored

  • Packet payloads
  • Requests or response bodies
  • Passwords, cookies or tokens
  • Webpage or message contents
  • Email and chat bodies
  • Uploaded or downloaded files

Where data lives

Browser preferences and aliases remain in local storage. Accepted history lives in local SQLite and is pruned after one hour by default. The database is not encrypted and is intended for a trusted single-user host.

Delete local SQLite history after stopping the server 
pnpm reset:local

05

Permission-free

Simulator

Twenty-four deterministic scenes make the full product useful before real capture is enabled—and make bugs, demos and screenshots repeatable.

Scenes include Movie Night, Netflix Premiere, calls, gaming, downloads, developer workflows, IoT, public Wi-Fi and a deliberately low-confidence regular beacon. Seeds reproduce metadata and timing; event IDs include the engine epoch so process restarts do not collide with persisted rows.

Headless local simulator 
PACKETHALO_SCENARIO=developer-laptop \
PACKETHALO_SEED=demo-7 \
pnpm --filter @packethalo/simulator dev
Remote delivery is explicit.The headless client accepts loopback HTTP by default. Non-local endpoints require HTTPS and PACKETHALO_ALLOW_REMOTE=1.

Real host metadata

Capture providers

The available real provider reads Linux operating-system socket tables. It does not open a packet-capture device.

Linux socket tables do not expose reliable per-flow byte counters, geography or ASN data. Those values remain zero or Unknown rather than being invented.

LAN is not public hosting.A non-loopback bind requires a 32–256 character token. The built-in server does not terminate TLS and is not an Internet-facing identity system.
08

Run beyond dev

Production

Production from source

Build all UIs, packages and services 
pnpm build
pnpm build:services
pnpm start:server

Start pnpm start:simulator in another terminal. Serve the built UIs with pnpm preview:web and pnpm preview:control.

Docker Compose

Complete local topology 
docker compose up --build

Open http://127.0.0.1:8080; controller is on 8081. The server uses a named data volume, health checks, a read-only filesystem and a non-root process. docker compose down preserves history; docker compose down -v intentionally deletes it.

10

When the light goes quiet

Troubleshooting

The screen is alive but no real flows appear

The browser simulator intentionally remains active. Check /health, then start the Linux agent on a Linux host. macOS and Windows providers are not implemented.

The phone controller is offline

Development binds to loopback. A different device needs authenticated appliance/LAN mode, the Pi address and a strong token.

LAN mode refuses to start

This is a safety gate. A non-loopback host requires PACKETHALO_CONTROL_TOKEN. Do not reuse the Docker-only container escape hatch for LAN exposure.

Docker has no live flows

Run docker compose ps, inspect server and simulator logs, then confirm /ready returns 200 and accepted events increase in /health.

Rendering is slow

Choose Ambient mode, lower particles and afterglow, enable reduced motion, close DevTools and test at 1080p.
