02 / Get running

From checkout to a real page.

The local tarball is installable; registry publication and release downloads are separate checks. These commands use the public source repository and Node.js 24.

Terminal / build and serve 
git clone https://github.com/OthmaneBlial/phoenixcss.git
cd phoenixcss
npm ci
npm run build
python3 -m http.server 8765

Open http://127.0.0.1:8765/examples/core.html or http://127.0.0.1:8765/examples/themed.html. To use the CSS in your own site, copy a generated file beside your page and link it like this:

HTML / after copying the file 
<link rel="stylesheet" href="./phoenix.core.min.css" />

Choose phoenix.min.css instead when you use the optional classes below. The files in dist/ are local build artifacts; npm publication must be verified separately.
