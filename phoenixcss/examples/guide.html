Start with the document

A short guide should be usable before it becomes an interface. Give sections clear headings, keep links recognizable, and let lists retain their markers. PhoenixCSS core adds readable defaults to that native structure without component classes.

Write the content first. Add classes when the layout needs them.

What the core file covers

  • Headings, paragraphs, links, lists, quotes, and code.
  • Tables whose cells and headers remain available on small screens.
  • Native form controls and visible keyboard focus.
