02 / THE TOOLKIT

Four ways to use Metra.

A

Inspect

Detect by signature, walk bounded metadata regions, and keep typed values and warnings separate.

metra --json photo.jpg
B

Change

Use set, delete, or copy where a tested writer can preserve layout and validate the result.

metra --set KEY=VALUE file
C

Create

Generate bounded metadata-oriented seeds for fixtures, pipelines, and repeatable tests.

metra --create-png Comment=... out.png
D

Scale

Run deterministic batches with bounded workers, streaming output, cancellation, and safety budgets.

metra --jsonl --jobs 4 -r photos/

04 / PROJECT LEDGER

Trust the boundary.

The status is intentionally split into what works, what is bounded, and what still needs evidence.

Working

  • Typed metadata model and stable identifiers
  • Defensive parsing with resource limits
  • Validated seeds and narrow atomic rewrites
  • Text, JSON, JSONL, CSV, TOML, YAML

Experimental

  • Selected MakerNote families
  • Proprietary RAW readers remain read-only
  • Writers often require existing fixed storage
  • Opt-in corpus differential harness

Planned

  • More real-world corpus evidence
  • Deeper tags and media structures
  • Additional writer and creator seams
  • Broader performance baselines
