02 / the thesis

The boundary is
the feature.

A

Useful without UIKit

The Rust core runs as a normal CLI. Shell behavior, filesystem policy, persistence, and limits can be tested before an iPhone build exists.

SwiftUI owns presentation. Explicit host providers own Apple capabilities. No second shell, no ambient launcher, no mysterious bridge.
