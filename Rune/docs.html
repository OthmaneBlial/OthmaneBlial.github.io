01 / portable core

Rust owns the workflow.

The CLI runs a Rust parser and planner. Commands receive a virtual filesystem and return bounded stdout, stderr, and status. Pipelines, redirections, scripts, loops, functions, command substitution, aliases, persistence, and cancellation remain inside the core.

rune-shelllexing + explicit execution plans
rune-fscanonical paths + approved roots
rune-coreregistry + session + output
rune-runtimebounded Lua, Python, JavaScript
rune-wasmWASI preview1 with explicit preopens
rune-packagemanifest + SHA-256 verification
cargo run -p rune-cli -- --root /tmp/rune-root -c "mkdir -p demo/src; echo 'fn main() {}' > demo/src/main.rs; tree demo"

02 / apple boundary

Swift presents.
Providers ask.

The source-only SwiftUI/UIKit layer talks to opaque Rust sessions through rune-ffi. It can render output, send commands, request cancellation, manage tabs, and surface host actions. Network, URL opening, clipboard, media, folders, and toolchains are explicit callbacks rather than ambient capabilities.

03 / security

Constrain first.

  • Filesystem: roots are canonicalized and symlinks cannot escape the approved VFS.
  • Growth: command input, output channels, scripts, archives, runtimes, persistence, and UI transcript are bounded.
  • Capabilities: host network, launch, clipboard, media, folder, and toolchain access require an injected provider; defaults are disabled.
  • Privacy: history redaction covers environment/network/private phone actions by default, while environment persistence is opt-in.

05 / release boundary

Alpha means alpha.

v0.1.0-alpha.10 is a public source preview of the portable foundation. It is not a stable iOS application, does not bundle Xcode or an SDK, and does not include a signed installable app. The changelog and roadmap keep those next gates visible.
