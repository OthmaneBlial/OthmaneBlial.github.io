THEMES & LOCAL BRAND KITS

a visual voice.

Twelve distinct palettes, measured typography and editable objects. Create a custom theme or import your own local logo and brand definition.

Native layout uses bundled OFL Carlito metrics. Arbitrary font shaping has a documented compatibility limit.

BUILT FOR YOUR MACHINE

A small, shared native engine.

The CLI and Tauri desktop use the same typed story, measured geometry and OpenXML engine. Preview follows that geometry; export stays editable.

Offline by default

Compilation, review, preview and export require no service or model. Your project stays local.

Optional drafting

Use your OpenAI-compatible endpoint, Ollama, LM Studio or Gemini. Approve the exact text and endpoint before sending.

Receipts bind exact story and presentation bytes to their theme and diagnostics. They prove consistency, not truth or authorship.
