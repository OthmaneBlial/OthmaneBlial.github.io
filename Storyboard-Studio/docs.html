LOCAL SETUP

Review the decision story before you render the deck.

Storyboard Studio is a Python 3.10+ FastAPI application with a dependency-free browser UI, deterministic no-key compiler, Narrative Doctor, and native PowerPoint renderer.

Install and run

git clone https://github.com/OthmaneBlial/Storyboard-Studio.git
cd Storyboard-Studio
make setup
make run

Open http://127.0.0.1:8000. The documented path creates an isolated .venv and runs without an account, API key, or remote model.

Create the bundled local proof

storyboard demo --bundle --output storyboard-demo.pptx

The command writes a synthetic editable deck plus its canonical story and Narrative Receipt. It does not claim user research or factual verification.

Compile, diagnose, export, verify

storyboard compile \
  --input examples/briefs/onboarding-decision.json \
  --output output/onboarding.story.json
storyboard doctor output/onboarding.story.json --format markdown
storyboard export \
  --input output/onboarding.story.json \
  --output output/onboarding.pptx \
  --bundle
storyboard verify output/onboarding.receipt.json

The Doctor checks narrative structure, evidence coverage, density, progression, ownership, and next actions deterministically. Receipt verification confirms hashes and internal references, not whether a claim is true.

Optional providers

The browser defaults to the local compiler. Gemini is available only when you explicitly select it for a draft and provide GEMINI_API_KEY through your process environment. A loopback-only OpenAI-compatible adapter supports local Ollama/LM Studio-style endpoints.

export GEMINI_API_KEY="your-key"
make run

Provider requests exclude local assets, evidence files, sources, and speaker notes. Read the complete provider capability and retention matrix ↗ before sending authorized material.

Local API

Interactive OpenAPI documentation is available at /docs while the local server runs. The versioned contract is published in the repository.

  • GET /api/health — readiness and optional-provider state.
  • GET /api/v1/providers — network, model, policy, retention, and configuration disclosure.
  • POST /api/v1/stories/decision-brief — compile a structured decision brief locally.
  • POST /api/v1/stories/doctor — diagnose a versioned story.
  • POST /api/v1/layout/preflight — find layout overflow before export.
  • POST /api/v1/bundles — export PPTX, story, and Receipt as a ZIP.

Privacy, compatibility, and known limits

Storyboard Studio creates no account, profile, analytics event, or shared presentation database. Generated server copies stay in the local output/ directory and expire after 24 hours. Selecting a remote provider sends only the disclosed bounded brief fields for that draft.

  • The current install path is clone + make setup; the package is not published on PyPI yet.
  • The showcase is an interactive product tour, not a hosted deck editor.
  • Fonts, effects, and viewer imports can differ across PowerPoint, LibreOffice, Keynote, and Google Slides.
  • The public research count remains zero until consented external sessions are completed.
