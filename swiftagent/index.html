01 / THE POINT

Delegate work without losing the thread.

SwiftAgent is for developers who like Claude Code but want a clearer operating surface around it. The app preserves what happened, shows the work in motion, and lets the next instruction continue the same conversation.

02 / WORKFLOW

One focused loop.

  1. 01

    Choose a workspace

    Keep file tools inside a dedicated project root.

  2. 02

    Describe the job

    Start a bounded task through the browser or WebSocket API.

  3. 03

    Watch the work

    See Claude responses, tool use, progress, and final state live.

  4. 04

    Continue with context

    Use the saved Claude session ID for the next useful instruction.

03 / SAFETY BY DEFAULT

Strict means
fail closed.

In strict mode, SwiftAgent will not launch a task unless Linux bwrap is installed and usable. It does not silently switch to an unsandboxed process.

fallback is a deliberate choice for a trusted local machine. It is visible in the UI and documented as unisolated—not dressed up as a sandbox.

04 / FIRST RUN

Useful in a few minutes.

Bring an authenticated Claude Code CLI, then run the local app. No hosted account or project upload is required by SwiftAgent.

terminal
git clone https://github.com/OthmaneBlial/swiftagent.git
cd swiftagent
make setup
make onboard
make dev

Then open http://127.0.0.1:5173 and verify the engine status before sensitive work.
