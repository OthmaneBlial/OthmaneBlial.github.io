WHAT STAYS NATIVE

Claude remains Claude.

Login, models, native sessions, CLI arguments, and permission modes remain owned by Claude Code. SwiftAgent does not copy credentials or translate its session into another agent's format.

WHAT SWIFTAGENT ADDS

Evidence around the run.

A normalized timeline, bounded native diagnostics, Git impact, separate safety layers, explicit test status, durable local history, and a redacted context preview before another agent starts fresh.

CLAUDE WORKFLOW

01

Detect without prompting

SwiftAgent checks the local executable and version path without spending tokens or reading a conversation.

02

Run in one workspace

The isolated adapter owns Claude's stream and maps only supported events into the common timeline.

03

Resume or hand off

Resume the same Claude session, or review a bounded redacted prompt before a different agent creates a new run.

HONEST BOUNDARY

No fake approval parity.

Claude tool events and resume are fixture-verified. Interactive approvals, plans, usage, and attachments are not exposed by this adapter. The exact live Claude CLI contract remains unknown when its version probe fails. SwiftAgent shows that state instead of turning a successful process launch into a compatibility claim.
