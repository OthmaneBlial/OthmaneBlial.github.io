CONTRIBUTOR CONTRACT

Prove before declaring.

The kit includes a fake agent, JSON schema, event fixture, security checklist, compatibility template, cancellation/resume checks, and a receipt-producing harness.

PROCESS BOUNDARY

Configuration, not installation.

The manifest supplies literal argv and a bounded environment allowlist. It cannot run a shell, replace a built-in ID, self-assign verified trust, download code, or silently update an executable.

TRUST IS SEPARATE

A passing fixture is not endorsement.

Every manifest-loaded integration remains Local custom. Community verified requires exact contract evidence, security review, distribution provenance, a named owner, and repository-assigned metadata. SwiftAgent never auto-installs from a catalog.
