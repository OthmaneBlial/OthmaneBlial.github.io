SWIFTAGENT FIELD NOTES

Local control,
clear boundaries.

QUICKSTART

terminal
git clone https://github.com/OthmaneBlial/swiftagent.git
cd swiftagent
make setup
make onboard
make dev

RUNTIME

One local process boundary.

The React browser app talks to FastAPI through REST and WebSocket events. The task manager validates requests, keeps five task slots active, starts queued work FIFO, and persists every task result to SQLite. Claude CLI stream-json output becomes visible messages, tool activity, and a resumable session ID.

SAFETY NOTES

Read this before running sensitive work.

strict requires usable Linux bwrap and fails before task launch if bwrap is unavailable. fallback is chosen explicitly in Settings and does not isolate the Claude process from files your local user can access. Workspace File API containment still applies, but it is not a substitute for process isolation.

SwiftAgent is loopback-only by default and has no user authentication. Do not expose it remotely without a trusted access layer that provides authentication and transport security.

OPERATIONS

Small, observable, recoverable.

/health is a liveness endpoint, /ready reports workspace readiness, and /api/engine/status diagnoses CLI and sandbox state. Incomplete tasks are marked failed after a restart rather than falsely left running. File reads, writes, and listings are bounded to protect the local service from oversized payloads.
