# Screenshot provenance

The desktop and mobile images in `assets/screenshots/` come from the `browser-e2e` job of [GitHub Actions run 35446357041](https://github.com/OthmaneBlial/AetherTerm/actions/runs/35446357041), on commit `dbaf5e9`. The Vim image comes from the same job in [run 35447709065](https://github.com/OthmaneBlial/AetherTerm/actions/runs/35447709065), on commit `99e7af4`. Both complete runs passed on Ubuntu 24.04. The screenshots were generated by `scripts/verify_browser.py`, downloaded from the runs' `chromium-screenshots` artifacts, visually inspected and copied byte-for-byte into this repository.

| `vim.png` | 1280 × 861 | `b5665ba157104fd1743a2c01eabdeb262c64b83f5c943ddb406de2ac7abda97d` |

For the desktop and mobile captures, the script installed the Python package, started a loopback server and real agent with disposable credentials, signed in through Chromium, opened a PTY, restarted the server, signed in again, and ran `cd /tmp`, `printf 'Live shell connected\n'` and `uname -s` in the second shell. It captured the desktop and 375 px layouts before running further interrupt and Unicode-output checks. In the later run, it opened actual Vim, typed `VIM_BROWSER_OK`, captured the edit screen, saved and quit, then read the file back through the PTY. No interface or terminal output was mocked. The pictured `browser-agent` and runner hostname belong to temporary CI environments, not a user deployment. The images show prototype commits; they do not prove remote TLS, a release download, a touch device or production readiness.
