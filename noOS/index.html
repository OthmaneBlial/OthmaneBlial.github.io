01 / THE BOOT PATH

From reset.
To your kernel.

The BIOS hands over control. noOS takes it from there.

  1. 01

    Boot sector

    The BIOS loads the 512-byte first stage at 0x7C00. It preserves the boot drive and loads stage two.

    boot/stage1.asm ↗
  2. 02

    Second stage

    Loads the kernel from disk, preserves the BIOS E820 memory map, checks A20, and installs a Global Descriptor Table.

    boot/stage2.asm ↗
  3. 03

    Protected mode

    Sets the protected mode bit, performs a far jump, and establishes the kernel’s 32-bit environment.

    boot/gdt.asm ↗
  4. 04

    Kernel entry

    Execution reaches 0x10000. The kernel initializes its terminal, interrupts, memory, and timer, then starts the shell.

    kernel/entry.asm ↗

Four commands.

Build, test, and debug →

cd noOS
make
make run

KNOW THE BOUNDARY

This is an experimental operating system for QEMU’s BIOS pc machine. Physical memory management currently covers the first 128 MiB. Physical hardware and UEFI are unvalidated; filesystem, process, and user mode work has its own roadmap gates.
